## هشدارهای مهم

- خریداران پنل **شبیه‌سازی‌شده**اند؛ ۵۵٪ سقف است، نه پیش‌بینی.
- مدل مالی **پیش‌بینی** نیست؛ تست انسجام و ریسک است.
- تحلیل، توصیه سرمایه‌گذاری، حقوقی یا مالیاتی نیست.
- اعداد دک چشمی روی تصویر ۲۳ اسلاید تأیید شده‌اند؛ هر جا با مدل فرق دارد، هر دو عدد آمده.
- جست‌وجوی وب برای رقبا در این اجرا در دسترس نبود؛ نام رقیب ساخته نشده و تحلیل در سطح دسته‌هاست.
